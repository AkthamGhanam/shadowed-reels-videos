Privacy Policy

Last updated: November 8, 2026

Shadowed Reels Uploader ("the app") is a private tool used only by the owner of the YouTube channel The Shadowed Reels.

What the app accesses

The app uses the YouTube Data API only on the owner's own channel, with these permissions: uploading videos (youtube.upload) and posting a comment on the owner's own videos (youtube.force-ssl).

What data is stored

The app does not collect, store, sell or share personal data from any user. It stores only the IDs of the videos it uploads, in the owner's own repository. Its access token is kept as an encrypted secret in the owner's GitHub account and is used only to call the YouTube Data API.

Third parties

The app uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. See the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Contact

For questions, open an issue at github.com/AkthamGhanam/shadowed-reels-videos.
